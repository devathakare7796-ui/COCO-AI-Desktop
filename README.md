# COCO AI

COCO AI is a modern desktop AI assistant developed by **Deva Thakare**.

## Features

* 🤖 AI Chat Assistant
* 🎤 Voice Assistant
* 🌐 Browser Control
* ▶️ YouTube Control
* 💬 WhatsApp Automation
* 💻 System Control
* 🧠 Memory System
* 🌦️ Weather Reports
* 🛠️ Automation
* 💡 Coding Assistant
* 🎮 Game Updater
* 🎨 Premium Modern UI

## Requirements

* Windows 10 or Windows 11 (64-bit)
* Internet connection
* Gemini API Key

## Installation

1. Download the latest release.
2. Extract the ZIP file or run the installer.
3. Launch **COCO AI.exe**.
4. Configure your Gemini API key.
5. Enjoy your personal AI assistant.
